# Bienvenue sur Bases du C aux normes 42

Ce site t'apprend à programmer en **C selon les normes de l'École 42**, que tu prépares la piscine 42 ou que tu veuilles compléter une formation BTS CIEL par une initiation au langage C.

## Ce que tu vas apprendre

- La structure d'un programme C et la compilation.
- Les types de base, les variables, les opérateurs.
- Les structures de contrôle : conditions et boucles.
- L'écriture de fonctions propres conformes à la Norm 42.
- Les tableaux, les chaînes de caractères et une première approche des pointeurs.

## Comment utiliser ce site

Chaque **support** combine :

- Un cours théorique avec des exemples commentés.
- Des exercices progressifs pour mettre en pratique immédiatement.

Commence par l'[Introduction](introduction/index.md), puis enchaîne les supports dans l'ordre.

## Outils nécessaires

- Un terminal Linux ou macOS (ou WSL sous Windows).
- Un éditeur de texte (VS Code, Vim, etc.).
- Le compilateur `cc` (clang ou gcc).
- `norminette` pour vérifier la conformité de ton code à la Norm 42.

```bash
pip install norminette
```

---

!!! tip "Astuce"
    Tous les exemples de code de ce site compilent avec `cc -Wall -Wextra -Werror`
    et passent `norminette` sans erreur. Utilise ces deux commandes pour valider
    ton propre code.
