# Glossaire

Définitions des termes essentiels rencontrés dans les supports.

## A

**Adresse mémoire**
: Numéro unique identifiant un emplacement dans la mémoire RAM. En C, l'opérateur `&` donne l'adresse d'une variable.

**Algorithme**
: Suite finie et ordonnée d'instructions permettant de résoudre un problème.

## B

**Bit**
: Plus petite unité d'information, valeur 0 ou 1.

**Bloc**
: Ensemble d'instructions délimité par des accolades `{ }`.

## C

**Compilation**
: Transformation du code source C en fichier exécutable par le processeur.

**Constante**
: Valeur qui ne change pas pendant l'exécution du programme. Définie avec `#define` ou `const`.

## D

**Déclaration**
: Instruction qui réserve un emplacement mémoire pour une variable ou annonce l'existence d'une fonction.

**Déréférencement**
: Accès à la valeur pointée par un pointeur, via l'opérateur `*`.

## E

**En-tête 42** (header 42)
: Bloc de commentaires obligatoire en haut de chaque fichier `.c` et `.h` dans les projets École 42.

## F

**Fonction**
: Bloc de code nommé et réutilisable qui reçoit des paramètres et retourne une valeur.

## L

**Langage compilé**
: Langage dont le code source est transformé en code machine avant exécution (ex : C, Rust).

**Langage interprété**
: Langage dont le code source est exécuté ligne par ligne par un interpréteur (ex : Python, JavaScript).

## M

**Mémoire (RAM)**
: Zone de stockage temporaire utilisée pendant l'exécution d'un programme.

## N

**Norm 42**
: Ensemble de règles stylistiques imposées par l'École 42 pour rendre le code lisible et uniforme.

**`norminette`**
: Outil Python officiel de l'École 42 qui vérifie la conformité du code à la Norm 42.

## P

**Paramètre**
: Variable reçue par une fonction lors de son appel.

**Pointeur**
: Variable qui stocke l'adresse mémoire d'une autre variable.

**Prototype**
: Déclaration d'une fonction sans son corps, indiquant son nom, ses paramètres et son type de retour.

## R

**Retour de fonction** (`return`)
: Instruction qui termine une fonction et renvoie éventuellement une valeur à l'appelant.

## T

**Type**
: Catégorie de donnée qui détermine la taille mémoire et les opérations possibles (ex : `int`, `char`).

## V

**Variable**
: Emplacement mémoire nommé qui stocke une valeur modifiable pendant l'exécution.
